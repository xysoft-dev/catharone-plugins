# Catharone plugin retired

Catharone no longer offers the external-agent plugin for Codex or Claude Code.
New connections and plugin requests are unavailable. Use the Catharone app for
companion conversations, memory controls and matching preferences.

You can remove Catharone from your agent host’s installed plugins. Reinstalling
or signing in again will not restore the integration.

Retirement does not delete existing Catharone conversations, memories or matching
preferences. Existing account data remains subject to Catharone’s
[Privacy Policy](https://www.cathar.one/privacy) and account deletion controls.
Copies retained by an external agent are managed in that host.
